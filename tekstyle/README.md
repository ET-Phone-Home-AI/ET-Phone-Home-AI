# TekStyle website

Static concept site for TekStyle. It needs no build step: open `index.html` or serve this folder.

It's a plain HTML/CSS/JS port of the approved React/Vite source (`TekStyle_Functional_Approved`). The design and copy are unchanged. The photos in `assets/` are crops of the approved concept screenshot.

## Before publishing
- The waitlist form is a demo. It does not store or send anything. Connect a secure form provider before going live.
- The artwork includes medical, performance and patent claims that need independent review. The site doesn't validate them.
